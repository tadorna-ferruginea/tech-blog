# Figma 分享卡编辑包

画布尺寸为 **1200 × 630 px**。

1. 将 `social-card-layout.svg` 拖入 Figma，作为背景、边框和文字版式。
2. 将 `mascot.png` 拖入同一画布，设为 **宽 555 px**、左侧 **100 px**、顶部 **50 px**。
3. 鸭子与水波是一个整体；请整体缩放或移动，不要拆开，以保留与网页页头完全一致的比例和位置。
4. 如导入 SVG 后文字显示为轮廓，请在 Figma 中新建两段文字并按下列内容替换；位置和色彩以 SVG 为准。
